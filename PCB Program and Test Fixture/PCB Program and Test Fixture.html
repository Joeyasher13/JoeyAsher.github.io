PCB Program and Test Fixture

This was created to serve as a modular station to test and program PCB's. I wanted a way to program and debug circuit boards without cluttering up my desk with wires and cords, so I made this station that can connect multple USB devices to control the device under test.

There are other solutions out there for this, but mine has a few distinct advantages.

  • Metal base allows 3D printed PCB fixtures with magnets to be easily positioned and replaced
  • Built in USB hub allows up to 4 devices to be connected with only one connection to the host computer
  • A single mounting pole makes it easy to position and replace different programming/debugging devices
